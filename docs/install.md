# Установка Revit MCP Chat

Плагин поддерживает Revit 2022, 2023 и 2024 и устанавливается отдельно от `rvt-mcp`. Для работы нужны оба компонента: Revit MCP Chat показывает панель и ведёт чаты, а `rvt-mcp` предоставляет MCP-инструменты Revit.

## Установка

1. Установите [`rvt-mcp`](https://github.com/yakovman1/rvt-mcp) по его официальной инструкции. Ожидаемый путь сервера: `%LOCALAPPDATA%\Bimwright\rvt-mcp\server\current\rvt-mcp.exe`.
2. Закройте Revit.
3. Распакуйте ZIP Revit MCP Chat в локальную папку.
4. В PowerShell запустите `install.ps1`. Чтобы сначала увидеть найденные версии и проверить расположение пакета, можно запустить `verify-package.ps1`.
5. Запустите Revit и откройте **Надстройки → Revit MCP Chat → AI Chat**.
6. На вкладке настроек выберите провайдера, укажите идентификатор модели и вставьте свой API-ключ. После сохранения поле очищается. Ключ шифруется Windows DPAPI и доступен только той же учётной записи Windows.

Установщик находит Revit по исполняемому файлу или пользовательской папке надстроек. Для тестовой установки можно явно передать годы и пути:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 `
  -RevitYears 2022,2024 `
  -InstallRoot "$env:LOCALAPPDATA\RevitMcpChat" `
  -AddinsRoot "$env:APPDATA\Autodesk\Revit\Addins"
```

`rvt-mcp` не скачивается и не изменяется этим установщиком. Если сервер не найден, установка панели продолжается, а PowerShell показывает ссылку на проект и инструкцию. Если Revit уже запущен, установщик выполняет MCP-handshake и проверяет, что каталог содержит Revit-инструменты. Если Revit закрыт, эта проверка выполняется при первом подключении из панели.

## Настройка ключей для организации

Для частного пакета подготовьте локальный JSON-файл с идентификаторами провайдеров и ключами:

```json
{
  "openai": "...",
  "anthropic": "..."
}
```

Соберите пакет командой:

```powershell
./packaging/build-release.ps1 -Configuration Release -AdminKeysFile C:\private\admin-keys.json
```

Сборка генерирует C#-источник во временной папке и включает ключи в агент. Исходник временно перезаписывается нулями и удаляется после сборки. Провайдерский ключ администратора не выводится в интерфейсе и не сохраняется в пользовательском settings.json. Ключ в бинарном файле клиента можно извлечь анализом файла или памяти процесса, поэтому этот вариант задаёт общий доступ для установки, но не является защитой секрета от пользователя с доступом к его файлам. Если ключ должен оставаться секретным, используйте серверный прокси.

Если у пользователя сохранён собственный ключ для того же провайдера, он используется вместо ключа администратора. Удаление пользовательского ключа возвращает доступ к встроенному ключу, если он настроен.

## Проверка MCP и диагностика

При подключении панель запускает `rvt-mcp.exe` с целевым PID процесса Revit. Агент выполняет MCP-initialize и загружает каталог инструментов. Должен быть доступен каталог с инструментами `revit_*`. Если сервер не найден, установите `rvt-mcp` по его инструкции и нажмите **Подключить**. Если handshake не проходит или Revit-инструменты отсутствуют, обновите `rvt-mcp` до совместимого релиза и перезапустите Revit.

Можно выполнить ту же проверку из распакованного пакета, когда Revit уже работает:

```powershell
./verify-package.ps1 `
  -RvtMcpPath "$env:LOCALAPPDATA\Bimwright\rvt-mcp\server\current\rvt-mcp.exe" `
  -RevitPid 12345
```

Замените `12345` на PID нужного процесса Revit. Скрипт не меняет конфигурацию `rvt-mcp`.

## Удаление

Закройте Revit и запустите:

```powershell
./uninstall.ps1
```

Удаляются файлы агента, надстройки и её Revit-манифесты. История, настройки и DPAPI-ключи пользователя остаются в `%LOCALAPPDATA%\RevitMcpChat`. Чтобы удалить их вместе с плагином, явно добавьте `-Purge`:

```powershell
./uninstall.ps1 -Purge
```

Удаление Revit MCP Chat не удаляет `rvt-mcp`.
